# MCA Notes Hub

Study resources for the **KTU Master of Computer Applications (MCA)** program —
semester-wise notes, question papers, syllabus, lab programs and video tutorials,
organized in one corporate-style portal.

## Use

- Open `index.html` in a browser, or visit the GitHub Pages site.
- Browse by semester (S1–S4), or use the search bar to find any resource.
- Supplementary tutorial pages live under `more_details/`, `Entrance/` and `video/`;
  downloadable material lives under `Download/`.
